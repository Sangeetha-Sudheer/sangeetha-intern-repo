# Cyber Security Guidelines

## Common Cyber Security Threats in Remote Work

Remote work can increase security risks because employees may use home networks, personal devices, cloud services, and online communication tools.

Common threats include:

- phishing emails and fake login pages;
- malicious links and attachments;
- weak or reused passwords;
- stolen credentials;
- malware and ransomware;
- unsecured public Wi-Fi;
- lost or stolen devices;
- outdated software;
- accidental sharing of confidential information;
- unauthorised access to unattended computers.

Being aware of these risks helps reduce the chance of a security incident.

## Best Practices for Keeping Devices and Accounts Secure

I can improve security by:

- using strong and unique passwords;
- enabling two-factor authentication where possible;
- using a password manager;
- keeping software and operating systems updated;
- locking my computer when I am away;
- avoiding suspicious links and attachments;
- using secure networks;
- installing software only from trusted sources;
- protecting sensitive information;
- reporting suspicious activity quickly.

## Why I Should Lock My Computer When Away

Locking my computer prevents another person from accessing company systems, files, messages, or accounts while I am away.

Even if I only leave my desk for a short time, an unlocked computer can expose confidential information.

Using automatic screen locking adds an extra layer of protection if I forget to lock the device manually.

## Phishing and Suspicious Links

If I receive a suspicious email, message, or link, I should not open the link or download the attachment immediately.

I should:

- check the sender carefully;
- look for unusual spelling or unexpected requests;
- avoid entering passwords through links in suspicious messages;
- confirm unusual requests through another trusted communication method;
- report suspected phishing attempts;
- delete the message after it has been reported if appropriate.

If I am unsure, I should ask before interacting with the message.

## Strong Passwords and Password Managers

A strong password should be long, difficult to guess, and unique for each account.

Reusing the same password across several accounts is risky because one compromised account could expose other accounts.

A password manager can:

- generate strong passwords;
- store unique passwords securely;
- reduce password reuse;
- make it easier to manage many accounts.

I should not store work passwords in insecure notes or plain-text files.

## Two-Factor Authentication

Two-factor authentication adds another security step in addition to a password.

For example, logging in may require both a password and a code from an authenticator app.

2FA is important because a stolen password alone may not be enough for an attacker to access the account.

I should enable 2FA on work accounts whenever it is available.

## Security Measures I Currently Follow

I already try to follow basic security practices such as:

- using passwords or biometric login on my devices;
- keeping my laptop and phone protected when I am not using them;
- avoiding suspicious links;
- keeping software updated;
- being careful about what information I share online.

I can improve further by making sure every important work account uses a strong unique password and 2FA where supported.

## How I Can Make Security a Habit

Security is easier to maintain when it becomes part of my normal routine.

I can build secure habits by:

- locking my computer whenever I leave my desk;
- checking links before opening them;
- using a password manager consistently;
- reviewing account security settings regularly;
- applying software updates promptly;
- using 2FA wherever possible;
- reporting suspicious activity instead of ignoring it.

Repeating these actions regularly makes security part of my normal work process.

## Steps I Will Take to Keep Passwords and Accounts Secure

I will:

1. use unique passwords for important accounts;
2. avoid reusing passwords;
3. use a password manager;
4. enable 2FA where available;
5. avoid sharing passwords through messages or documents;
6. review login alerts and suspicious activity;
7. change a password immediately if I believe it has been exposed.

## What I Would Do if I Suspected a Security Breach

If I suspected suspicious activity or a security breach, I would act quickly.

I would:

- stop interacting with suspicious content;
- disconnect from affected services if necessary;
- change compromised passwords;
- review account sessions and sign out unknown devices;
- enable or verify 2FA;
- report the incident to the appropriate Focus Bear contact or manager;
- provide clear details about what happened;
- follow any instructions provided by the company.

I would avoid hiding the issue or trying to solve a serious security incident without informing the team.

## Cyber Security Habit I Will Follow at Focus Bear

One new habit I will consistently follow is locking my computer whenever I step away from my desk, even for a short time.

I will also make sure automatic screen locking is enabled so the device locks itself after a short period of inactivity.

This reduces the risk of unauthorised access to work accounts and company information.

## Reflection

Cyber security is not only the responsibility of security specialists.

As a team member, my everyday behaviour can either reduce or increase security risk.

Strong passwords, 2FA, device locking, careful handling of links, and fast reporting of suspicious activity are simple actions that can protect company and user data.

The most important improvement for me is to make these behaviours consistent habits rather than only thinking about security after something goes wrong.
