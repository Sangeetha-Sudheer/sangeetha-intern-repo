# Agile Workflows & Kanban

## How a Kanban Board Works

A Kanban board is a visual way to track work as it moves through different stages.

Each task is represented by a card, and the card moves across columns as the work progresses.

A simple Kanban board may contain columns such as:

- Not Started
- In Progress
- Blocked
- Ready for Review
- Approved / Done

This helps the team quickly understand what work is waiting, what is currently being worked on, what is blocked, and what has been completed.

## What the Different Columns Represent

### Not Started

Tasks that are planned but have not been started yet.

### In Progress

Tasks that are actively being worked on.

### Blocked

Tasks that cannot move forward because of a problem, missing information, dependency, or technical issue.

### Ready for Review

Tasks where the implementation is complete and waiting for review or validation.

### Approved / Done

Tasks that have been reviewed, accepted, and completed.

## How Tasks Move Through the Board

A task normally starts in Not Started.

When I begin working on it, I move it to In Progress.

If I cannot continue because of a blocker, I move it to Blocked.

When I finish the implementation and evidence, I move it to Ready for Review.

After the work is approved, I move it to Approved or Done.

The person working on the task should keep its status updated so that the board accurately represents the current workflow.

## Benefits of Limiting Work in Progress

Limiting work in progress means avoiding too many active tasks at the same time.

This can help because:

- it reduces context switching;
- it makes priorities clearer;
- it helps tasks get finished before new ones are started;
- it makes blockers easier to notice;
- it reduces overload;
- it improves focus.

For me, this is useful because I work better when I can focus on one important task at a time.

## How Kanban Helps Manage Priorities and Avoid Overload

Kanban makes priorities visible.

If the most important tasks are near the top of the board, I can see what should be worked on next.

It also prevents overload by encouraging limits on the number of tasks in progress.

Instead of opening many tasks at once, I can complete one or two before starting more.

This makes the workflow easier to manage and reduces unfinished work.

## How I Can Improve My Workflow Using Kanban Principles

I can improve my workflow by:

- keeping task statuses updated;
- moving blocked work into a Blocked column instead of leaving it in progress;
- limiting the number of tasks I work on at the same time;
- finishing current work before starting lower-priority tasks;
- reviewing the board regularly;
- making sure completed work is moved to review or done promptly.

This would make my progress clearer and help me stay focused.
